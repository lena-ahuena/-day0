# Мой мир · Real Life RPG

## Быстрый тест

Открой index.html в браузере. Вкладка «День» показывает календарь и задания. Нажми «Завтра» или выбери 26 ноября 2026 года для встречи в 10:30.

## GitHub Pages

1. Создай репозиторий GitHub (для публичного Pages на бесплатном тарифе — публичный).
2. Загрузи файлы из архива в корень репозитория.
3. В Settings → Pages выбери Deploy from a branch, ветку main и папку / (root), нажми Save.
4. Открой выданный GitHub Pages адрес в Safari на iPhone. Поделиться → На экран «Домой».
5. После полной онлайн-загрузки и установки service worker можно пользоваться приложением офлайн. При обновлении приложения обнови версию кеша в sw.js.

Все изменения и достижения хранятся локально в браузере. Храни резервные копии из раздела «Настройки» отдельно. Mac и iPhone имеют независимый прогресс; для переноса экспортируй JSON и импортируй его на втором устройстве. Импорт заменяет текущие данные. Никогда не загружай JSON с личными заданиями в публичный репозиторий. В исходной версии уже есть три демонстрационных квеста на 26 ноября; перед публикацией можешь заменить их данные в index.html.

## Игровая механика

100 XP = один уровень. XP за квест делятся между выбранными направлениями. Подзадачи начисляют часть награды, завершение всех подзадач — полную. Отмена/удаление пересчитывают опыт. Архив сохраняет заработанный опыт. Повторение генерирует отдельный квест при открытии даты. Изменение повторяющегося квеста касается конкретной даты; остановить будущие повторы можно в разделе «Архив». Пропущенные дни не штрафуются.

Файлы не используют сервер, внешние библиотеки и внешние API.
